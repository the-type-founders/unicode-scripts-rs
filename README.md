# Unicode Scripts [![Package][package-img]][package-url] [![Documentation][documentation-img]][documentation-url] [![Build][build-img]][build-url]

The package provides detection of scripts from Unicode codepoints.

The implementation is based on the [Unicode Character Database][ucd] and
[detect-writing-script].
